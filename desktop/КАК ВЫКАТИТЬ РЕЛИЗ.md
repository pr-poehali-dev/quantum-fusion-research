# Как выкатить новую версию StressTester

Порядок для полной и Lite-сборки. Занимает несколько минут, редеплой
сайта или правка настроек сервера НЕ нужны.

## 1. Собрать установщик

- Полная сборка: `desktop/000 Release/Собрать УСТАНОВЩИК.bat`
- Lite-сборка: `desktop/000 Release/Собрать УСТАНОВЩИК LITE.bat`

На выходе — `StressTester_Setup_<версия>.exe`
и `StressTester_Setup_<версия>_Lite.exe`.

## 2. Загрузить файл

Админка → **Стресс-тесты → Версии тестера** → блок «Новая версия».

Есть два пути:

1. Файл уже лежит в нашем хранилище → «Показать файлы» и выбрать его.
2. Файл на Яндекс.Диске → вставить публичную ссылку и «Проверить ссылку».

Для автообновления лучше **наше хранилище**: программа скачивает файл
напрямую, без страниц с проверками. Яндекс.Диск оставляем для архива
старых версий.

## 3. Заполнить карточку

- **Номер версии** — как в самой программе: `1.0.7.0`. Слово «Lite»
  писать не нужно, сборка определяется автоматически по имени файла.
- **Что нового** — короткий список изменений, его увидят и посетители
  сайта, и стенд в окне обновления.
- **Сразу опубликовать на сайте** — оставить включённым.

Сохранить. Полная и Lite окажутся в одной карточке версии.

## 4. Проверить

В том же разделе сверху блок **«Автообновление программы»**: для полной и
Lite должно быть написано «стенды обновятся до <версия>» с зелёной
галочкой. Если стоит предупреждение — сборка не опубликована.

Проверить ответ вручную:

```
GET https://functions.poehali.dev/<stress>?action=launcher_version
GET https://functions.poehali.dev/<stress>?action=launcher_version&channel=lite
```

Должны прийти непустые `latest_version` и `download_url`.

На стенде в логе программы: «Установлена актуальная версия» либо окно
«Доступна версия X».

## Как это устроено

- Программа спрашивает версию без авторизации, до входа.
- Сервер берёт **самую свежую опубликованную** сборку нужного вида прямо
  из каталога версий, поэтому выкладка не требует передеплоя функции.
- Ссылка на файл — временная (час) и ведёт прямо на `.exe`.
- `latest_version` очищается до цифр (`1.0.7.0 Beta` → `1.0.7.0`), потому
  что программа сравнивает его со своей версией файла. Человеческое
  название приходит отдельно, в `version_label`.
- Если каталог пуст, берутся запасные настройки сервера:
  `STRESS_LAUNCHER_VERSION`, `STRESS_LAUNCHER_DOWNLOAD_URL`,
  `STRESS_LAUNCHER_RELEASE_NOTES`.

## Откат

Снять «На сайте» у неудачной версии (иконка глаза) — стенды и посетители
снова получат предыдущую опубликованную сборку.
