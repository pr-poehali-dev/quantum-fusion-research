# Как запустить проект на своём сервере

Проект состоит из трёх частей:
1. **Фронтенд** — сайт (React + Vite), статика (HTML/CSS/JS).
2. **Бэкенд** — Python-функции (`/backend`), общаются с базой и Telegram.
3. **База данных** — PostgreSQL.

Ниже — пошаговая инструкция «с нуля» на чистом Linux-сервере (Ubuntu 22.04).
Команды выполняются в терминале сервера (по SSH).

---

## 0. Что понадобится

- VPS/сервер с Ubuntu (минимум 1 CPU / 1 GB RAM).
- Доменное имя, направленное A-записью на IP сервера.
- Доступ по SSH (`ssh root@IP_сервера`).

---

## 1. Установка базового ПО

```bash
sudo apt update && sudo apt upgrade -y
# Node.js 20 (для сборки фронтенда)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs git nginx python3 python3-pip python3-venv postgresql postgresql-contrib
```

Проверка версий:
```bash
node -v        # должно быть v20.x
python3 --version
```

## 2. Настройка базы данных PostgreSQL

```bash
sudo -u postgres psql
```
В консоли psql выполни (замени ПАРОЛЬ на свой):
```sql
CREATE DATABASE begraphics;
CREATE USER begraphics_user WITH PASSWORD 'ПАРОЛЬ';
GRANT ALL PRIVILEGES ON DATABASE begraphics TO begraphics_user;
\c begraphics
GRANT ALL ON SCHEMA public TO begraphics_user;
\q
```

Строка подключения (понадобится для бэкенда):
```
postgresql://begraphics_user:ПАРОЛЬ@localhost:5432/begraphics
```

### Перенос структуры таблиц
Все миграции лежат в папке `db_migrations/`. Применить их по порядку:
```bash
cd /var/www/app/db_migrations
for f in $(ls V*.sql | sort -V); do
  echo "=== $f ==="
  PGPASSWORD=ПАРОЛЬ psql -U begraphics_user -h localhost -d begraphics -f "$f"
done
```
> Если в коде используется отдельная схема (см. `MAIN_DB_SCHEMA`), создай её заранее:
> `CREATE SCHEMA t_p72635010_quantum_fusion_resea;`

## 4. Сборка фронтенда

Фронтенд обращается к бэкенду по URL из `backend/func2url.json`.
На своём сервере эти URL нужно заменить на свои адреса функций (см. шаг 5),
либо настроить проксирование `/api/...` через Nginx.

```bash
cd /var/www/app
npm install
npm run build
```
Готовый сайт окажется в папке `dist/` — это статика, которую отдаёт Nginx.

## 5. Запуск бэкенд-функций (Python)

На poehali бэкенд — это «облачные функции». На своём сервере их проще
обернуть в маленький HTTP-сервис. Самый простой способ — Flask-обёртка.

Создай `/var/www/app/backend/server.py`:
```python
import importlib.util, json, os
from flask import Flask, request

app = Flask(__name__)
BACKEND_DIR = os.path.dirname(__file__)

class Ctx:
    request_id = "local"

def load_handler(name):
    path = os.path.join(BACKEND_DIR, name, "index.py")
    spec = importlib.util.spec_from_file_location(f"fn_{name}", path)
    mod = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(mod)
    return mod.handler

@app.route("/<name>", methods=["GET","POST","PUT","PATCH","DELETE","OPTIONS"])
def call(name):
    handler = load_handler(name)
    event = {
        "httpMethod": request.method,
        "headers": dict(request.headers),
        "queryStringParameters": dict(request.args),
        "body": request.get_data(as_text=True),
        "isBase64Encoded": False,
    }
    res = handler(event, Ctx())
    return (res.get("body",""), res.get("statusCode",200), res.get("headers",{}))

if __name__ == "__main__":
    app.run(host="0.0.0.0", port=8000)
```

Установи зависимости и переменные окружения:
```bash
cd /var/www/app/backend
python3 -m venv venv
source venv/bin/activate
pip install flask psycopg2-binary
# зависимости отдельных функций (если есть requirements.txt)
find . -name requirements.txt -exec pip install -r {} \;
```

Переменные окружения (создай файл `/var/www/app/backend/.env` и подгружай его):
```bash
export DATABASE_URL="postgresql://begraphics_user:ПАРОЛЬ@localhost:5432/begraphics"
export MAIN_DB_SCHEMA="t_p72635010_quantum_fusion_resea"
export TELEGRAM_BOT_TOKEN="ваш_токен_бота"
export TELEGRAM_MANAGER_CHAT_ID="-100..."   # id группы менеджеров
export AWS_ACCESS_KEY_ID="..."              # если используется загрузка файлов
export AWS_SECRET_ACCESS_KEY="..."
export B2B_PASSWORD="..."
export CANCEL_ORDER_PASSWORD="..."
```

Запуск как сервис (systemd) — `/etc/systemd/system/backend.service`:
```ini
[Unit]
Description=BeGraphics backend
After=network.target postgresql.service

[Service]
WorkingDirectory=/var/www/app/backend
EnvironmentFile=/var/www/app/backend/.env
ExecStart=/var/www/app/backend/venv/bin/python server.py
Restart=always

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl daemon-reload
sudo systemctl enable --now backend
sudo systemctl status backend
```
Теперь функции доступны по `http://IP:8000/orders`, `http://IP:8000/quiz` и т.д.

> После этого в `backend/func2url.json` пропиши свои адреса
> (например `https://ваш-домен/api/orders`) и пересобери фронтенд (`npm run build`).

## 6. Nginx: сайт + проксирование API

`/etc/nginx/sites-available/app`:
```nginx
server {
    listen 80;
    server_name ваш-домен.ru;

    root /var/www/app/dist;
    index index.html;

    # фронтенд (SPA)
    location / {
        try_files $uri /index.html;
    }

    # бэкенд-функции
    location /api/ {
        proxy_pass http://127.0.0.1:8000/;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
```bash
sudo ln -s /etc/nginx/sites-available/app /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

## 8. Telegram-бот уведомлений

Бот шлёт менеджерам сообщения о событиях (новый заказ, лид из квиза,
приход товара под заказ). Что нужно:

1. Создай бота у **@BotFather** (`/newbot`) — получишь `TELEGRAM_BOT_TOKEN`.
2. Создай группу менеджеров, добавь туда бота.
3. Узнай `chat_id` группы (добавь в группу @getmyid_bot или @RawDataBot) —
   для групп это отрицательное число вида `-100...`.
4. Пропиши `TELEGRAM_BOT_TOKEN` и `TELEGRAM_MANAGER_CHAT_ID` в `.env` (шаг 5).
5. Перезапусти бэкенд: `sudo systemctl restart backend`.

Отправка реализована в `backend/*/tg_notify.py` (функция `notify_managers`).
Если токен/chat_id не заданы — уведомления просто не отправляются, сайт работает.
