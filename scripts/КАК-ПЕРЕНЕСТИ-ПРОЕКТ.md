# Перенос проекта на локальную машину

Скачанный архив проекта содержит **только код**. Данные лежат отдельно:

| Что | Где хранится | Как забрать |
|-----|--------------|-------------|
| Код сайта и функций | архив «Скачать код» | уже у вас |
| База (заказы, товары, склад) | PostgreSQL на серверах платформы | скрипт ниже |
| Файлы (фото, счета, отчёты) | файловое хранилище | скрипт ниже |
| Пароли и ключи | секреты проекта | переписать вручную |

## 1. Скачать данные

```bash
python scripts/скачать-данные.py ВАШ_ПАРОЛЬ_АДМИНКИ
```

Появится папка `scripts/выгрузка`:

- `dump.sql` — вся база (~18 МБ, 95 таблиц)
- `files/` — все файлы (~2,9 ГБ, 1300+ штук)

Скачивание файлов идёт около 10 минут. Прервалось — запустите снова,
уже скачанное пропустится.

По умолчанию история цен и метрики стресс-тестов выгружаются без
содержимого — это 48 тысяч строк логов, для работы они не нужны.
Нужны целиком:

```bash
python scripts/скачать-данные.py ВАШ_ПАРОЛЬ_АДМИНКИ --всё
```

## 2. Поднять базу локально

Нужен установленный PostgreSQL.

```bash
createdb myproject
psql myproject -f scripts/выгрузка/dump.sql
```

## 3. Прописать доступы

Функциям нужны те же переменные, что заданы в секретах проекта.
Обязательные:

- `DATABASE_URL` — адрес вашей локальной базы,
  например `postgresql://postgres@localhost:5432/myproject`
- `MAIN_DB_SCHEMA` — `t_p72635010_quantum_fusion_resea`
- `AWS_ACCESS_KEY_ID` и `AWS_SECRET_ACCESS_KEY` — для файлового хранилища
- `ADMIN_KEY` — пароль входа в админку

Остальные (Telegram, парсер, стресс-тесты) — по мере надобности,
полный список в разделе «Секреты» проекта.

## 4. Запустить сайт

```bash
npm install
npm run dev
```

## Про файлы

Ссылки на файлы в базе ведут на хранилище платформы. Пока проект там
живёт, картинки на локальной копии будут открываться из интернета —
скачанные копии нужны как резерв на случай отключения проекта.

Чтобы сайт брал файлы локально, положите папку `files` в `public/` и
замените в базе начало ссылок:

```sql
UPDATE t_p72635010_quantum_fusion_resea.products
SET image_url = replace(image_url,
    'https://cdn.poehali.dev/projects/ВАШ_КЛЮЧ/bucket/', '/files/')
WHERE image_url LIKE '%cdn.poehali.dev%';
```

Ссылки встречаются и в других таблицах (статьи, сборки, отчёты) —
проще пройтись по ним тем же способом.
