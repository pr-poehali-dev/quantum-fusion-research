=== ВОРКЕР РАСПОЗНАВАНИЯ СЧЕТОВ (локальный сервер с GPU) ===

Этот воркер крутится на ТВОЁМ сервере (2080 Ti 22GB), сам забирает задачи
с сайта, распознаёт фото счёта через локальную модель Ollama (qwen2-vl)
и отправляет результат обратно. Сайт его НЕ вызывает напрямую — воркер
сам ходит к облаку, поэтому проброс портов для него НЕ нужен.

--------------------------------------------------------------------
ШАГ 1. Установить Ollama + модель
--------------------------------------------------------------------
    curl -fsSL https://ollama.com/install.sh | sh
    ollama pull qwen2-vl:7b
    # проверка:
    ollama run qwen2-vl:7b "привет"

(модель 7B свободно влезает в 22 ГБ VRAM)

--------------------------------------------------------------------
ШАГ 2. Поставить зависимости воркера
--------------------------------------------------------------------
    pip install requests

--------------------------------------------------------------------
ШАГ 3. Задать токен (тот же, что в секрете RECEIPT_WORKER_TOKEN на сайте)
--------------------------------------------------------------------
    export RECEIPT_WORKER_TOKEN="вставь_сюда_длинную_случайную_строку"
    # (опционально, если другой URL функции)
    # export RECEIPT_BACKEND_URL="https://functions.poehali.dev/de7a55a6-8858-43db-b39f-e5d791bc39b4"

--------------------------------------------------------------------
ШАГ 4. Запустить воркер
--------------------------------------------------------------------
    python worker.py

В консоли пойдут строки "[worker] задача #N ..." когда менеджер загрузит счёт.

--------------------------------------------------------------------
ШАГ 5 (по желанию). Сделать автозапуск через systemd
--------------------------------------------------------------------
Создай /etc/systemd/system/receipt-worker.service:

    [Unit]
    Description=Receipt OCR worker
    After=network.target ollama.service

    [Service]
    Environment="RECEIPT_WORKER_TOKEN=твой_токен"
    ExecStart=/usr/bin/python3 /path/to/worker.py
    Restart=always
    User=твой_пользователь

    [Install]
    WantedBy=multi-user.target

Затем:
    sudo systemctl daemon-reload
    sudo systemctl enable --now receipt-worker

--------------------------------------------------------------------
БЕЗОПАСНОСТЬ
--------------------------------------------------------------------
- Ollama держи на localhost (по умолчанию). Наружу не открывай:
      sudo ufw deny 11434
- Воркер сам инициирует соединения к облаку, входящие порты ему не нужны.
- Токен RECEIPT_WORKER_TOKEN должен совпадать на сайте и в воркере.

--------------------------------------------------------------------
КАК ЭТО РАБОТАЕТ (поток)
--------------------------------------------------------------------
1. Менеджер в админке: Склад -> "Принять по счёту" -> фото.
2. Сайт кладёт фото в облако, создаёт задачу (status=NEW).
3. Воркер забирает задачу (worker_pull), шлёт фото в Ollama.
4. Модель возвращает JSON позиций.
5. Воркер отправляет результат (worker_result) -> сайт делает матчинг.
6. Менеджер видит экран сверки -> правит -> "Принять" -> партии на складе.
