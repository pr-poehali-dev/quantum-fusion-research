## v5.36 | 2026-06-24 | StressRunner: датчики через LibreHardwareMonitor (без HWiNFO)

### Суть
- Отказ от HWiNFO Shared Memory (форматы памяти «съезжали» между версиями).
  Датчики читаются НАПРЯМУЮ через LibreHardwareMonitorLib — метка и значение
  всегда из одного объекта-сенсора, ничего не разъезжается. HWiNFO не нужен.

### desktop/StressRunner
- HardwareMonitor.cs: обёртка над LibreHardwareMonitor (CPU/GPU/MB/RAM),
  ReadAll() → список {Hardware, Name, Type, Unit, Value}.
- HwInfoReader переписан на HardwareMonitor (Read/IsAvailable/Debug),
  EnsureRunning больше ничего не запускает.
- MetricsCollector: сбор min/max/avg по типам Temperature/Load/Fan/Clock/Power.
- DebugWindow: список датчиков железо·имя/тип/значение/ед.
- Удалён HwInfoSharedMem.cs. Пакет LibreHardwareMonitorLib 0.9.4.

## v5.35 | 2026-06-24 | StressRunner: парсер SM2 — эвристика меток (размер элемента 448)

### desktop/StressRunner
- HwInfoSharedMem: у HWiNFO размер элемента 448 б (расширенная структура с
  UTF-8/UTF-16 полями) — жёсткие смещения строк давали мусор/двойную кодировку.
  Теперь метка/единица вытаскиваются эвристикой (самая длинная ASCII-подстрока
  с буквами из зоны строк = англ. метка). Числа читаются из конца (4×double) —
  они и так были верны. Метки стали читаемыми, распознавание метрик по типу+слову.

## v5.34 | 2026-06-24 | StressRunner: фикс парсера Shared Memory + reg HWiNFO

### Главный фикс
- HwInfoSharedMem: парсер читал структуру со сдвигом (выравнивание double) →
  метки-мусор и значения 9e+24, метрики не собирались. Теперь double-блок
  читается по фактическому размеру элемента (sizeElem-32 из заголовка),
  строки — в Windows-1251 (кириллица), мусорные значения фильтруются (|v|<1e9).
- App: регистрация CodePagesEncodingProvider (для 1251). Пакет
  System.Text.Encoding.CodePages.

### desktop/StressRunner
- HwInfoReader.ImportReg: перед запуском HWiNFO импортирует
  StressTests\HWinfo\HWiNFO64_settings.reg (применяет сохранённые настройки).

### Frontend
- Пресет Superposition: путь без bin —
  StressTests\Superposition Benchmark\Superposition.exe.

## v5.24 | 2026-06-24 | StressRunner: портативная сборка (один .exe + флешка)

### desktop/StressRunner
- .csproj: один самодостаточный .exe (PublishSingleFile + SelfContained +
  сжатие). На целевом ПК .NET ставить не нужно. Сборка одной командой:
  `dotnet publish -c Release -o publish`.

  (StressTests\OCCT\OCCT.exe) от корня exe + переменные окружения.

- Runner: запуск программ и сбор отчётов через Paths.Resolve — относительные
  пути работают на любом ПК.

### Frontend (StressProfilesTab)
- Пресеты теперь подставляют относительные пути StressTests\... вместо C:\...
- Подсказка под полем «Программа» про относительные пути и флешку.
