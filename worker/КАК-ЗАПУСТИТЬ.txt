  ВОРКЕР РАСПОЗНАВАНИЯ СЧЁТОВ — КАК ЗАПУСТИТЬ

ОДИН РАЗ (подготовка):

1. Установи Ollama:        https://ollama.com/download
2. Установи Python 3.11+:  https://www.python.org/downloads/
   (при установке поставь галочку "Add Python to PATH")
3. Скачай модель в командной строке:
       ollama pull qwen2.5vl:3b      (быстрый, ~4-5 ГБ видеопамяти)
   или ollama pull qwen2.5vl:7b      (точный,  ~8-10 ГБ видеопамяти)
4. Открой нужный .bat в Блокноте и впиши токен воркера в строку:
       set "RECEIPT_WORKER_TOKEN=сюда_твой_токен"
   (токен берётся из секрета проекта RECEIPT_WORKER_TOKEN)


ЗАПУСК (каждый день):

  Просто дважды кликни:
      start_worker_3b.bat   — быстрый воркер (модель 3B)
      start_worker_7b.bat   — точный воркер  (модель 7B)

  Запускай ТОЛЬКО ОДИН из них (3B или 7B), а не оба сразу,
  если видеопамяти не хватает на обе модели.


ЧТО ПРОИСХОДИТ САМО:

  - Воркер сам поднимает сервер Ollama (отдельно запускать не нужно).
  - Следит, чтобы сервер не падал, и перезапускает его при сбое.
  - Держит модель в видеопамяти, чтобы не выгружалась через 5 минут.
  - Если сам воркер упадёт — .bat перезапустит его через 5 секунд.


ОСТАНОВИТЬ:

  Закрой окно воркера (крестиком) — он аккуратно погасит Ollama за собой.


ЕСЛИ ЧТО-ТО НЕ ТАК:

  - Лог сервера Ollama пишется рядом в файл:  ollama_serve.log
  - Если в окне пишет "Команда 'ollama' не найдена" —
    значит Ollama не установлена или не добавлена в PATH.
  - Если пишет про токен — впиши его в .bat (см. пункт 4 выше).
