ОДИН РАЗ (подготовка):

1. Установи Ollama:        https://ollama.com/download
2. Установи Python 3.11+:  https://www.python.org/downloads/
   (при установке поставь галочку "Add Python to PATH")
3. Скачай модель в командной строке:
       ollama pull qwen2.5vl:3b           (быстрый, ~4-5 ГБ видеопамяти)
   или ollama pull qwen2.5vl:7b           (точный,  ~8-10 ГБ видеопамяти)
   или ollama pull qwen2.5vl:7b-q4_K_M    (квант 7B: точность ~как 7B, ~5-6 ГБ —
                                           ЛУЧШИЙ выбор для карты на 12 ГБ,
                                           вся модель влезает на GPU = 100%% GPU)
4. Открой нужный .bat в Блокноте и впиши токен воркера в строку:
       set "RECEIPT_WORKER_TOKEN=сюда_твой_токен"
   (токен берётся из секрета проекта RECEIPT_WORKER_TOKEN)


ЗАПУСК (каждый день):

  Просто дважды кликни:
      start_worker_3b.bat      — быстрый воркер (модель 3B)
      start_worker_7b.bat      — точный воркер  (модель 7B, нужно ~9 ГБ VRAM)
      start_worker_7b_q4.bat   — точный КВАНТ (7B-q4_K_M, ~5-6 ГБ) —
                                 РЕКОМЕНДУЕТСЯ для карты на 12 ГБ:
                                 вся модель на GPU, без тормозов от CPU

  Запускай ТОЛЬКО ОДИН из них, а не несколько сразу,
  если видеопамяти не хватает на несколько моделей.

  ПРОВЕРКА, что всё на видеокарте: в командной строке набери  ollama ps
  В колонке PROCESSOR должно быть 100%% GPU. Если есть проценты CPU —
  модель не влезла целиком; возьми квант (q4) или модель 3B.


ЧТО ПРОИСХОДИТ САМО:

  - Воркер сам поднимает сервер Ollama (отдельно запускать не нужно).
  - Следит, чтобы сервер не падал, и перезапускает его при сбое.
  - Держит модель в видеопамяти, чтобы не выгружалась через 5 минут.
  - Если сам воркер упадёт — .bat перезапустит его через 5 секунд.


EXCEL и PDF:

  - Excel (.xlsx/.xls) и текстовые PDF разбираются автоматически —
    библиотеки (openpyxl, pypdf, pdf2image) ставятся сами при первом запуске .bat.
  - Если присылаешь PDF-СКАН (фото внутри PDF), для него нужен poppler:
      1. Скачай poppler для Windows:
         https://github.com/oschwartz10612/poppler-windows/releases
      2. Распакуй и добавь папку \Library\bin в системный PATH.
    Текстовые PDF и Excel работают БЕЗ poppler.


ОСТАНОВИТЬ:

  Закрой окно воркера (крестиком) — он аккуратно погасит Ollama за собой.


ЕСЛИ ЧТО-ТО НЕ ТАК:

  - Лог сервера Ollama пишется рядом в файл:  ollama_serve.log
  - Если в окне пишет "Команда 'ollama' не найдена" —
    значит Ollama не установлена или не добавлена в PATH.
  - Если пишет про токен — впиши его в .bat (см. пункт 4 выше).
